# MoneyMoves font inventory

These files are local production inputs used to reproduce the channel style. They are not automatically copied into the UXP extension or release packages.

| Family           | Intended use                              | Files                               |
| ---------------- | ----------------------------------------- | ----------------------------------- |
| Peace Sans       | Oversized display titles and map labels   | OTF, TTF                            |
| BBH Bartle       | Editorial display alternates              | TTF                                 |
| LT Superior Mono | UI-like labels, data, captions, and ASCII | Regular, Medium, Semibold, Bold OTF |
| Press Start 2P   | Pixel accents                             | TTF                                 |

Before any release or redistribution, add the applicable license files and confirm that each license permits bundling. Until then, install the fonts locally on the build machine and keep release artifacts dependent on installed fonts.
